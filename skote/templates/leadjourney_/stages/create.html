¿Qué es un Stage?

Un Stage es una etapa del journey que agrupa varios steps relacionados. Cada stage tiene un prompt principal que será procesado por un agente IA.

Después de crear el stage, podrás agregar steps específicos que detallan las tareas granulares.

Tips para el Prompt:
  • Sé específico en las instrucciones
  • Define el formato de respuesta esperado
  • Usa variables para datos dinámicos
  • Incluye ejemplos si es necesario
